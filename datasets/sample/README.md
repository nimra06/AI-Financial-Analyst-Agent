# Sample datasets

Use these files to demo the app or as templates for your own data.

| File | Rows | Description |
|------|------|-------------|
| `template_monthly_pl.csv` | 3 | Minimal starter template — copy and extend |
| `retail_monthly_pl.csv` | 24 | Retail monthly P&L (Jan 2023 – Dec 2024) |
| `saas_monthly_pl.csv` | 24 | SaaS monthly P&L with growth profile |
| `retail_with_categories.csv` | 60 | Monthly P&L + expense category breakdown |

## Required columns (monthly P&L)

- **date** — month (e.g. `2024-01-01`)
- **revenue** — numeric

Optional: `cogs`, `opex`, `category`, `amount`

See the project [README](../../README.md) for aliases and validation rules.
